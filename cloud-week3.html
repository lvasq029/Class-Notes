Compute Spectrum

From Server-Based to Serverless

Serverless doesn't mean there's no server. It means you don't set up or manage one. Pick a service to see where it sits.

IaaS vs PaaS

Why the Billing Differs

GKE conceptually sits between the two: the managed infrastructure of an IaaS with the developer orientation of a PaaS.

Compute Engine (IaaS)App Engine (PaaS)
You getServers, networking, storagePreset runtimes, managed services
You payFor what you allocateFor what you use
ControlCustomizable installs (web server, DB, middleware), configurable disk space and I/OWrite code in a self-contained environment with access to RAM, file systems, networking interfaces
Trade-offSlow and costlyIndependent, rapid scaling

Containers

Containers vs VMs

A container groups your code and its dependencies. It scales like PaaS but gives nearly the same flexibility as IaaS.

Kubernetes

Clusters, Nodes, Containers

Kubernetes is a container orchestration tool. Google Kubernetes Engine (GKE) is the managed version, built on open-source Kubernetes, and it manages containers automatically based on specs like CPU and memory. Build a cluster below: click a node to add a container to it.

GKE CLUSTER

Cluster

The big unit under GKE. A group of computers (nodes) working together to run applications.

Node

Think of it as a VM, like a Compute Engine instance with its own OS and CPU settings.

Container

A small unit running on a node. Each can run a separate application.

Kubernetes lets you: install the system on local servers, manage container networking and data storage, deploy apps, and monitor containers with health checks. GKE's equivalents elsewhere: Amazon EKS and Azure AKS.
Cloud Run

Managed Serverless Containers

A managed compute platform that runs containers. Serverless, built on Knative (an open API and runtime environment on Kubernetes), and it scales up and down automatically.

HTTPS comes free
Client→ HTTPS →Cloud Run proxy→Your container

By default your app lives on a unique subdomain of *.run.app, or you can use your own domain. Cloud Run generates a valid SSL certificate, configures SSL termination with secure settings, and decrypts incoming requests before forwarding them to your app.

Cheat Sheet

The Five-Minute-Before-The-Exam Version

Spectrum

Compute Engine (IaaS) → GKE (hybrid) → App Engine (PaaS) → Cloud Run (serverless platform) → Cloud Functions (serverless logic).

Cloud Functions

Small single-purpose functions that respond to events. Node.js, Python, Go. Billed only while code runs.

Container

Standalone package of your app and what it needs to run. Shares the host OS kernel, starts as fast as a process.

Kubernetes / GKE

Orchestrates containers. A cluster is a group of nodes (VMs) running apps. Hybrid between IaaS and PaaS.

Cloud Run workflow

Write code → build and package as a container image → deploy to Cloud Run → get an HTTPS URL.

Cloud Run billing

Autoscales up and down. Charged only while a container handles requests. VMs charge for idle capacity.
