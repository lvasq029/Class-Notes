Data Types

Structured or Unstructured?

Structured data lives in tables, rows and columns. Unstructured data is documents, media and files, roughly 80% of all data. Classify each example.

Cloud Storage

Storage Classes: Pick by Access Frequency

Every class has unlimited storage (no minimum object size), worldwide access and locations, low latency, high durability, and geo-redundancy. They differ in how often you expect to read the data.

Buckets and Versioning

Buckets, Objects, and Object Versioning

Buckets

Files are organized into buckets. Each has a unique name and a geographic location. Ideal location: where latency is minimized.

Integration

Works with BigQuery, Cloud SQL, App Engine, Firestore and Compute Engine. Import/export data to Cloud SQL and BigQuery; store App Engine logs and Firestore backups.

Versioning demo

Upload a new version of the same object, with versioning on or off.

Relational Databases

Databases and Cloud SQL

A database is a collection of information organized so it can easily be accessed and managed. Relational databases are the most common: RDBMS = relational = SQL databases.

Good fit when

  • You have a well-structured data model
  • You need transactions
  • You join data across tables for complex combinations

Cloud SQL

  • Engines: MySQL, PostgreSQL, SQL Server
  • Google applies updates, manages backups, configures replication
  • Workloads under 64 TB

Reasons to use it

  • No software to install or maintain
  • Scales to 64 cores, 400+ GB RAM, 30 TB storage
  • Automatic replication; 7 backups included in instance cost
  • Encrypted on Google's networks and at rest; network firewall

Cloud Spanner

The other managed relational service. SQL-based, horizontally scalable and globally available.
